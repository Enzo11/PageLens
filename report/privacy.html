Privacy policy

Last updated: 26 October 2026

PageLens is a browser extension that analyses the page or GitHub repository you are looking at. It has no server and no account, and it collects nothing about you.

What PageLens reads

  • The current page, only after you click the PageLens icon. It reads structure, styles, colours, fonts, links, image sizes, script and stylesheet addresses, and timing data that your browser already recorded.
  • The page's response headers, through one ordinary request to the same address, sent without your cookies.
  • Names of cookies and local or session storage keys that page scripts can see. Never their values.
  • Cookie flags (Secure, HttpOnly, SameSite, expiry), only if you click "Check cookie flags" and approve Chrome's permission prompt. Values are discarded as soon as Chrome returns them.
  • Public GitHub data in GitHub mode, from api.github.com and raw.githubusercontent.com.

PageLens never reads anything you type into forms, never sees passwords, and strips query strings and fragments from every address it reports.

What PageLens stores

Everything is stored in your browser (chrome.storage.local) on this computer only:

  • Your settings (role, theme, history on or off).
  • Scan history: page address without query string, page title, scores and the titles of findings. Up to 12 checks per page and 60 pages. Turn it off or clear it in the History view.
  • A one-hour cache of GitHub results, for the last 15 repositories.

Nothing is synced, uploaded or shared.
